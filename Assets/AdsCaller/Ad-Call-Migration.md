# Ad Call Migration

Open **Ads Caller > Ad Call Migration**, or expand **Migrate old ad manager calls** in the Setup Wizard.

1. Choose the Assets folder containing gameplay scripts. Add any other SDK or wrapper implementation folders to **Exclude folders** (semicolon-separated).
2. Click **Scan Project**. Each manager/type appears once, with call and type-reference counts. The default list uses ad-specific type/method names, including `Moneylitica.ShowIntertitial`. Singleton access alone and gameplay names such as `ShopSequenceRewards` do not qualify. Use **Show non-ad types too (advanced)** or the manager filter to reveal wrappers whose names and methods give no indication of advertising.
3. Select managers and expand their rows. Map each distinct method signature to the intended ad action. Names and spelling do not control the mapping. Argument values may differ between occurrences. Overloads have separate mappings when their symbols resolve; unresolved calls are grouped by receiver, method and argument count.
4. Click **Preview Selected Replacements**, inspect the before/after calls and skipped occurrences, then **Replace Selected Calls**. The preview checks for new compiler errors and blocks Apply when any are introduced, including a missing AdsCaller.Core assembly reference. Preview must be regenerated after changing the selection or mappings. Asset changes invalidate the scan; source dependencies and the active target/defines are rechecked before applying.
5. Let Unity compile, inspect the Console, test the changed gameplay actions, and rescan for remaining references. Compilation does not prove equivalent gameplay behavior.

For example, mapping `Moneylitica.Instance.ShowIntertitial(placeholder, format, extra)` to **Interstitial** generates `global::AdsMediator.Instance.ShowInterstitial()`. All old arguments, including any side effects from evaluating them, are deliberately discarded. `global::` avoids conflicts with local namespaces/types. The original statement's semicolon remains in place. Banner mappings also discard old positions/options and use the mediator's default behavior.

Rewarded mappings retain the chosen success and optional failure callbacks. When switching a method to Rewarded, the tool suggests its one or two compatible callbacks; review their success/failure order. With resolved methods, the selector follows declared parameter order, so named arguments can appear in a different order at each call site. Unresolved methods use source argument order. Parameterless lambdas (including empty blocks, multiline bodies and comments) are preserved in full even if the old wrapper cannot resolve; the preview compiler-checks their conversion to the mediator's Actions. Arguments that are missing, custom delegate values and incompatible callbacks are reported for review. Unmapped calls and calls used as values/conditions, conditional access and expression-bodied calls remain unchanged. Overlapping selected calls are skipped.

The scanner uses Unity's bundled Roslyn parser and active player-assembly symbols. It resolves aliases and typed variables when compilation references are available. If a removed wrapper cannot resolve, explicit type/singleton receivers can still be mapped; these rows are marked unresolved. It does not infer a type from an unresolved local variable. Comments and strings are not calls. Type references such as fields/casts are listed for manual review, not changed into AdsMediator fields automatically.

Only writable C# gameplay files under Assets are migrated. Ads Caller itself, known SDK roots, Plugins, MMPHandler, Editor and Tests folders are excluded, as are calls inside the target manager's own type. Add other vendor folders to the exclusions. Scanning covers the **current build target and active preprocessor branches**; switch targets/defines and rescan to cover other branches. Scripts outside active player assemblies are reported. Reflection strings, DLL internals, scene/prefab UnityEvents and arbitrary dynamically discovered wrappers are outside this source migration's scope.

Mappings and scan preferences are saved in `ProjectSettings/AdsCallerAdCallMigration.json`. Backups, hashes and a preview report are saved under `AdsCallerMigrationBackups/AdCalls/`, outside Assets. Every affected file is checked against its scan snapshot before writing. I/O failures roll back files written by that operation. **Restore Last Migration** restores the latest applied backup and refuses to overwrite later edits. After restoring, older applied migrations can be restored in reverse order. Backups are retained; ordinary Unity Undo does not undo source-file edits.

The editor implementation is shared by Android, Amazon, Unity 6 CrossPromo and Unity 2022 CrossPromo. It is included in the core unitypackage and UPM exports and introduces no player dependency or additional compiler DLLs.
