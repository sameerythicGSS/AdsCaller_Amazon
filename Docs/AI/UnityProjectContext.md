# Unity project context

Analyzed 2026-09-30. This is the TestingAmazonAds editable Ads Caller release source; no Git repository is present. Unity 6000.0.79f1.

Shared AdsCaller.Core owns AdsMediator, provider registry, result/session contracts, fullscreen leases, analytics and feedback UI. Online providers are alternatives: Android owns consent and MAX/AdMob adapters; Amazon owns MAX and optional AdMob. CrossPromo owns Addressables UI and a local/remote catalog. The bootstrap/setup editor assembly discovers providers without linking their runtime assemblies. Build Automator is independent in Assets/Editor/BuildAutomator.

Runtime UI uses uGUI and persistent provider MonoBehaviours. Public fields and existing serialized GUIDs are compatibility surfaces; configuration uses ScriptableObjects. The shared popup lives under Resources/AdsCallerUI so all legacy and UPM compositions can load it. Input System is optional for CrossPromo and accessed through the core shortcut helper; Addressables and Newtonsoft remain mandatory.

Source metadata and shared files must remain synchronized across all four releases. CoreRelease.json holds content hashes, and AdsCallerAssetIndex.json supports GUID lookup after UPM relocation. Use Tools/adscaller_upm.py to build distributions. Existing archive releases are immutable. Validation tools create disposable fixtures under the Android source Validation directory. Live Unity MCP currently points to an unrelated consumer project, so do not mutate that Editor for these fixes.

2026-10-28 catalog-free media export: the catalog checkbox previously emptied gameEntries/runtimeCatalog and URLs but kept database artwork (Unity 6 reproduced at 12,464,250 bytes). AdsCallerUpmExport now excludes TextureImporter/AudioImporter/VideoClipImporter assets under the resolved CrossPromo Database before building payloads and asset indexes, and clears their serialized preview references in exported prefabs/scenes. Empty catalogs, UI graphics, render textures and Addressables configuration remain included. Source assets are never temporarily rewritten. Shared exporter/UI guidance and CoreRelease hashes are synchronized across all four maintained sources. Tools/validate_catalog_export.py covers both catalog modes, both delivery formats, omitted media metadata/index entries, dangling media GUIDs, preserved UI and source fingerprints. CrossPromo tarballs are about 80 KB; complete installers still exceed 2 MB because Core ships two editor branding PNGs totaling 2,416,397 bytes.
